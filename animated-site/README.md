# Enhanced Animated Portfolio Website

This is an enhanced version of the portfolio website with modern animations and improved visual effects.

## ✨ Features

### 🎨 Advanced Animations
- **Welcome Overlay**: Animated particle background with typing effect
- **Smooth Transitions**: CSS-based transitions and transformations
- **Scroll Animations**: Elements fade in and slide up as you scroll
- **Hover Effects**: Interactive card hover effects with smooth transitions
- **Floating Shapes**: Background animated shapes for visual interest
- **Ripple Effects**: Button click animations
- **Parallax Scrolling**: Subtle parallax effects on background elements

### 🔧 Interactive Features
- **Responsive Navigation**: Mobile-friendly hamburger menu
- **Back to Top Button**: Smooth scroll to top functionality
- **Form Validation**: Contact form with real-time validation
- **Lazy Loading**: Images load as they come into view
- **Smooth Scrolling**: Anchor links with smooth scroll behavior

### 🎯 User Experience
- **Glass Morphism**: Modern frosted glass effect on cards and sections
- **Gradient Accents**: Beautiful gradient colors throughout
- **Keyboard Navigation**: Full keyboard accessibility
- **Performance Optimized**: Debounced scroll events and efficient animations
- **Reduced Motion Support**: Respects user's motion preferences

## 🚀 Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Advanced animations, grid, flexbox, glass morphism effects
- **Vanilla JavaScript**: No dependencies, pure JS
- **Canvas API**: Particle animation system
- **Intersection Observer**: Efficient scroll animations
- **CSS Variables**: Theme customization

## 🎭 Animation Types

1. **Fade Animations**: Elements fade in smoothly
2. **Slide Animations**: Content slides in from different directions
3. **Scale Animations**: Cards and elements scale on interaction
4. **Rotate Animations**: Profile ring and social icons rotate
5. **Pulse Animations**: Logo and icons pulse gently
6. **Typing Effect**: Text appears with typing animation
7. **Gradient Shifts**: Background gradients shift dynamically
8. **Float Animations**: Profile picture floats gently

## 📱 Responsive Design

- **Desktop**: Full-width layout with multi-column grids
- **Tablet**: Optimized grid layouts
- **Mobile**: Single column layout with hamburger menu

## 🎨 Customization

To customize colors, edit the CSS variables in `styles/main.css`:

```css
:root {
    --primary-color: #00c6ff;
    --secondary-color: #0072ff;
    --accent-color: #ff3366;
    /* ... more variables */
}
```
