# Personal Blog & Portfolio

A modern, artistic personal blog showcasing technology, art, and creative projects.

## 🎨 Two Versions Available

This repository now contains **two versions** of the website:

### 1. **Enhanced Animated Version** (New! ✨)
Located in `animated-site/` folder
- Advanced CSS animations and transitions
- Particle effects with Canvas API
- Glass morphism design
- No external animation libraries
- Pure vanilla JavaScript
- Ripple effects and parallax scrolling
- Optimized performance

### 2. **Original Version**
Located in `docs/` folder
- Classic design with AOS library
- Proven and stable
- Lighter file size

**Landing Page:** `index.html` - Choose your preferred version!

## Features

### Common Features (Both Versions)
- Responsive design for all devices
- Project showcase (AI/ML, Electronics, Robotics)
- Art gallery with beautiful images
- Blog section
- Contact form
- Professional typography

### Enhanced Version Additional Features
- 🎭 Animated particle background
- ✨ Typing effect welcome screen

- 💫 Interactive hover effects
- 🎨 Glass morphism UI elements

### Original Version
- HTML5
- CSS3

## 🚀 Quick Start

### View Online
Visit the live site: [Your GitHub Pages URL]

### Local Development

1. Clone this repository:
   ```bash
   git clone https://github.com/Abhiroop-24/Personal-blog.git
   cd Personal-blog
   ```

2. Open in browser:
   - **Landing Page**: Open `index.html`
   - **Enhanced Version**: Open `animated-site/index.html`
   - **Original Version**: Open `docs/index.html`

3. No build process required - just open in your browser!
