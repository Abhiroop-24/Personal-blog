# Personal Blog & Portfolio

A modern, artistic personal blog showcasing technology, art, and creative projects.

## Features

- Responsive design with modern animations
- Project showcase (AI/ML, Electronics, Robotics)
- Art gallery
- Blog section
- Contact form with Netlify Functions
- AOS (Animate On Scroll) animations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- AOS Library
- Font Awesome Icons
- Netlify Functions (for contact form)

## Local Development

1. Clone this repository
2. Open `public/index.html` in your browser
3. For the contact form to work, deploy to Netlify
